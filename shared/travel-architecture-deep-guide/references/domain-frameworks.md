# 跨文明艺术、建筑与文化研究框架
此 Skill 面向世界各地区、所有历史时期的建筑、艺术、城市、考古、宗教、物质文化和博物馆。**先识别对象的地理、时代、媒介、社会语境，再选择方法**；不得把中国古代建筑、欧洲古典传统或任何单一文明作为默认标准。

## 共同研究维度（按相关性选择）
1. **对象与年代**：名称、位置、作者/工匠/社群、年代与改建层位；区分原物、复制、修复和复原。
2. **形式与媒介**：空间、比例、构图、材料、工艺、色彩、光线、观看方式及身体经验。
3. **社会历史**：赞助人、权力、经济、贸易、宗教、阶级、性别与制度；仅在证据支持时提出因果。
4. **思想与意义**：仪式、图像志、象征、文本与观众接受；避免把当代解读冒充历史原意。
5. **比较与交流**：同一时期和不同地区的作品，区分相似性、传播路径、直接影响和独立发展。
6. **遗产生命史**：毁损、搬迁、收藏、殖民背景、修复、争议和当代展示。

## 按对象启用的专业方法
- **世界建筑史**：东亚木构、南亚寺庙、伊斯兰建筑、地中海古典建筑、欧洲中世纪与文艺复兴、非洲及美洲本土建筑、工业化与现代/当代建筑等；采用该传统适用的构造、类型、制度和空间分析，不套用另一传统的等级术语。
- **绘画与视觉艺术**：图像描述、构图、色彩、笔触、透视、媒介、风格归属、赞助与观看史；包括中国书画、欧洲油画、版画、摄影和当代艺术。
- **雕塑与宗教艺术**：体量、材料、工艺、姿态、属性物、铭文、祭仪和图像身份；涵盖佛教、基督教、伊斯兰、印度教及其他传统，尊重各自概念和禁忌。
- **考古与古代遗址**：地层、分期、发掘报告、遗址布局、重建假说；不可把推测复原当作现场事实。
- **石窟、壁画与岩画**：编号体系、方位、图像层位、题记、残损、重绘、可达性；具体术语与研究传统随地区而变。
- **城市与景观**：街道、地块、地形、水系、公共空间、权力象征、基础设施、园林与景观实践。
- **博物馆与收藏**：作品真伪和归属、来源史、陈列语境、策展选择、保存修复和伦理争议。
- **文化与物质生活**：服饰、器物、工艺、饮食、日常空间、贸易网络和社会习俗；不把文化解释简化成建筑样式。

## 跨文化解释的防误读
避免用“先进/落后”线性排序文明；不要以西方艺术分期覆盖亚洲、非洲和美洲历史，也不要将东方文化视为单一整体。风格标签必须定义适用地区与时段。比较需要说明证据和局限，不把相似外观直接等同文化传播。尊重不同学科与地区的命名习惯。
