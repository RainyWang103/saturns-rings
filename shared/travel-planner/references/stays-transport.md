# 住宿与交通选择

## 住宿：区域 → 酒店 → 房型与条款

先用实际动线比较住宿区域：到核心项目与枢纽的门到门时间、晚餐/演出后返程、行李路段、坡道台阶、电梯、噪声与休息、地方特色及预算。安全描述依据可靠当前信息，不凭街区印象贴标签。

再筛选少量有明确取舍的酒店，如动线省心、酒店体验突出、价格舒适度均衡；不按评分单独排序，不把所有候选说成一样好。说明多花的钱换来了什么，换酒店是否值得。未有日期和预算时可先比较区域与酒店定位，不伪造实时房价或余房。

具体预订比较统一入住/退房日期、人数、房型、床型、早餐、币种与退改条件；核对两人全程含税总价、额外收费、定金、可退押金、支付时点、取消截止及当地时区。双床/大床按用户要求核实，不假设同行关系决定床型。晚到、跨午夜保房、行李寄存、无电梯等影响执行的事项列待办；评论中的单次噪声或服务投诉不直接认定为常态。

输出「区域理由 → 主推荐与条件备选 → 总价和条款 → 未核项及入口」。价格差来自不同条件时明确说明，不把不可退价与可退价直接当同类比较。

## 交通：比较完整旅行成本

对实际有竞争力的飞机、铁路、自驾、包车或正规小团，比较门到门耗时、两人总费用、行李、疲劳、可用游览时间和改动灵活性。无需为每段列齐所有交通方式。

- 飞机计入机场接驳、值机/安检/边检、取行李；航班核实沿用既有票面来源硬规则。
- 铁路计入车站位置、提前到站、换乘、行李寄取与末班；不同车站不可混用。
- 自驾计入驾驶资格、路况、收费、停车、限行和驾驶负担；必要政策按目标日期查官方资料。
- 包车/小团核对上车点、语言、团型、停留时长、包含费用、取消、超时和接送范围；不能用产品名称推定能自由调整。

先给适合本次路线的推荐及代价，再按排程规则核算逐段时间。不要仅为票价便宜而增加大量转场，或把站到站时间当作可用日程。
