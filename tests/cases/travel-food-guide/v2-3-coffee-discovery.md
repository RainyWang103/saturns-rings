# Coffee Discovery V2.3 — 回归案例

以下是测试提示和人工验收标准，不是生产环境硬编码品牌清单，也不是已执行的实地研究。

| 提示 | 验收重点 |
|---|---|
| 推荐新加坡咖啡 | 同时发现精品手冲、创意特调及 Kopi；识别 Alchemist 的品牌与 The Mill 等分店空间差异；不只依据全球咖啡榜 |
| 新加坡最好的特调 | 独立搜索 Signature Drinks；说明饮品名、门店、菜单核实日期和常驻/限定状态；不能虚构现售 |
| 东京推荐手冲 | 只需精品咖啡轨道；不强制加入果咖；评价豆源、烘焙与萃取 |
| 首尔推荐创意咖啡 | 以风味创新、配方完成度和饮品时效为核心，不因缺少手冲奖项扣分 |
| 墨尔本咖啡路线 | 本地烘焙与意式咖啡文化、门店体验、交通时间；不依赖新加坡品牌白名单 |
| 推荐新加坡美食 | 既有目的地美食雷达仍能发现餐厅、田鸡、娘惹菜、酒吧；咖啡模块不覆盖餐厅逻辑 |
| 比较 Alchemist 与 Apartment | 品牌与具体门店消歧；分开评价杯中品质和建筑空间；不编造菜单或排名 |
| 推荐某家季节限定咖啡 | 若找不到当前菜单证据，标注历史饮品/供应未知，不作现售承诺 |
