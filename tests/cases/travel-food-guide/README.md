# Travel Food Guide V2 离线回归案例
本目录不随 Skill 打包，案例只用于测试，不是运行时默认餐厅偏好或事实来源。必须实际查证才能判定结果。
案例：大连海鲜火锅（地方食材与当前品质）、锦州烧烤（不排队与非网红偏好）、两家精品咖啡（出品与行程）、东京日料（技术与预约）、巴黎 fine dining（近期菜单与高价风险）、意大利地方馆（传统与季节）、高分营销店、低曝光潜力小馆、主厨更换、过期菜单、同名分店、过敏风险。
分别测试 L1/L2/L3；单店判断、城市精选、两店比较、点菜、文化专题、行程适配；对比短交付与长交付是否保持相同事实门槛。核验推荐力度和证据可信度分离、负面证据检查、非固定本地特色排序、3–5家默认精选但不凑数。重大身份/菜单/预订/过敏误报一票否决。
记录：输入｜研究来源与日期｜输出｜推荐理由｜证据等级｜负面证据｜时效风险｜人工评价。静态 CI 通过不等于真实餐饮品质测试通过。
